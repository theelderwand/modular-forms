# Identity MF-008: Three-Term Eta-Quotient Relation

## Statement

```
  η(2z)⁴ η(4z)⁻² η(8z)⁻² η(16z)⁴
  -2·η(1z)² η(2z)⁻¹ η(4z)⁻² η(8z)³ η(16z)²
  + η(1z)⁴ η(2z)⁻² η(8z)⁻² η(16z)⁴
  = 0
```

**Weight:** 2 | **Level:** 32 | **Character:** trivial

## Proof

### Step 1: Modularity
Each term is an eta-quotient with `d | 32`, weight `(1/2)∑e_d = 2`,
satisfying Newman's criteria and Ligozat holomorphicity — hence in
`M_2(Γ₀(32))` with trivial character.

### Step 2: Sturm Bound
[SL₂(Z):Γ₀(32)] = 48, so B = (2/12)·48 = 8.

### Step 3: Verification
The q-expansion vanishes through `q^8` (verified to `q⁵⁰⁰`).
By Sturm, the combination is identically zero. ∎
