# Identity MF-005: Three-Term Eta-Quotient Relation

## Statement

```
  η(1z)⁻³ η(2z)³ η(3z) η(4z)² η(6z)³ η(8z)² η(12z)⁻² η(24z)²
  -2·η(1z)⁻² η(2z) η(3z)² η(4z) η(6z)⁻¹ η(8z)⁴ η(12z)³
  + η(1z)⁻¹ η(3z)³ η(4z)³ η(8z)² η(12z)⁻¹ η(24z)²
  = 0
```

**Weight:** 4 | **Level:** 24 | **Character:** trivial

## Proof

### Step 1: Modularity
Each term is an eta-quotient with `d | 24`, weight `(1/2)∑e_d = 4`,
satisfying Newman's criteria and Ligozat holomorphicity — hence in
`M_4(Γ₀(24))` with trivial character.

### Step 2: Sturm Bound
[SL₂(Z):Γ₀(24)] = 48, so B = (4/12)·48 = 16.

### Step 3: Verification
The q-expansion vanishes through `q^16` (verified to `q⁵⁰⁰`).
By Sturm, the combination is identically zero. ∎
