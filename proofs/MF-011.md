# Identity MF-011: Three-Term Eta-Quotient Relation

## Statement

```
  η(1z)⁴ η(2z)⁻² η(4z)² η(8z)² η(16z)⁻² η(32z)⁴
  -2·η(1z)⁴ η(4z)⁻³ η(8z)² η(16z)³ η(32z)²
  + η(1z)⁴ η(2z)² η(4z)⁻⁴ η(8z)⁴ η(16z)⁻² η(32z)⁴
  = 0
```

**Weight:** 4 | **Level:** 32 | **Character:** trivial

## Proof

### Step 1: Modularity
Each term is an eta-quotient with `d | 32`, weight `(1/2)∑e_d = 4`,
satisfying Newman's criteria and Ligozat holomorphicity — hence in
`M_4(Γ₀(32))` with trivial character.

### Step 2: Sturm Bound
[SL₂(Z):Γ₀(32)] = 48, so B = (4/12)·48 = 16.

### Step 3: Verification
The q-expansion vanishes through `q^16` (verified to `q⁵⁰⁰`).
By Sturm, the combination is identically zero. ∎
