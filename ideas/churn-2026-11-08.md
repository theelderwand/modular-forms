# Churn Report — New Identity Directions (2026-11-08)

Exploration beyond the 45 proven eta-quotient linear relations
(MF-001..015 + W-001..030). Four directions attempted.

## Direction 1 — Theta function identities: CLEAN NEGATIVE (no new identities)

**What was searched.** Linear relations among Jacobi theta functions
θ₂, θ₃, θ₄ at levels q^d, d ∈ {1,2,4,8,16}, in three weights:
- Weight 1/2: the 15 series θ₂(q^d), θ₃(q^d), θ₄(q^d) themselves.
- Weight 1: all 120 pairwise products.
- Weight 2: fourth powers θ₂⁴, θ₃⁴, θ₄⁴ (d ∈ {1,2,4,8,16}).
q-expansions to q^100 (index 400 in units of q^{1/4}), exact rational
nullspace via SymPy. Script: `scripts/theta_search.py`
(raw output: `/tmp/theta_out.txt`).

**Candidates found: 74 relations — ALL classical.**
Every relation found is a consequence of the classical duplication family:
- θ₃(q) + θ₄(q) = 2θ₃(q⁴) and θ₃(q) − θ₄(q) = 2θ₂(q⁴)
  (even/odd split of the square sum), and the same at q², q⁴, ...
- θ₂(q)² = 2θ₂(q²)θ₃(q²)
- θ₃(q)² + θ₄(q)² = 2θ₃(q²)², θ₃(q)θ₄(q) = θ₄(q²)²
- Jacobi's quartic: θ₃(q)⁴ = θ₂(q)⁴ + θ₄(q)⁴

All weight-1 relations are these weight-1/2 identities multiplied by a
common theta factor. Nothing outside the classical duplication/Jacobi
family appeared.

**Verification status.** Relations verified to 100 terms exactly; all
identified as classical (proof by even/odd split or standard duplication).

**Novelty notes.** None new. The search is a useful method validation:
it recovers exactly the known duplication family and nothing else,
which increases confidence that the nullspace machinery is sound.
No candidates written to `candidates_churn.json` from this direction.

## Direction 2 — Higher levels (64, 96): 421 NEW CANDIDATES

**What was searched.** Even weights (2, 4) at levels 64 and 96, trivial
character. Enumerate holomorphic eta-quotients (Newman + Ligozat),
sparse (3–4 term) ℚ-linear relations, screen vs known MF/W
(exact duplicates, oldforms, q→q^m substitutions), verify survivors
to 200 terms.

**Method note (computational).** The Python enumerator could not handle
level 96 (12 divisors; the recursion tree has ~10¹⁰ leaves). Built a
DP-guided enumerator in C (`/tmp/enum96b.c`, suffix-count pruning):
N=96 w=2 → 21,520 edicts in 19s; N=96 w=4 → 951,191 edicts in 14s.
For the nullspace step at N=96 w=2 (16,084 genuinely-new-at-96 edicts
in 21 shift groups), used an echelon + sparsify method
(`scripts/echelon.py`): reduce mod p, then exact QQ nullspace on each
dependency's support set. During this work two bugs were found and
fixed: (a) a sign-normalization in the dedup/substitution screen that
was not sign-canonical (it let MF-001 itself slip through as a
"candidate" at level 64); (b) a float leak in the character label
(`d ** r` with negative r returns float — see Direction 3).

**Candidates found.**
- Level 64, weight 2: **6** (file `candidates_churn_level64w2.json`).
- Level 64, weight 4: **30** (file `candidates_churn_level64w4.json`).
- Level 96, weight 2: **385** (201 three-term, 184 four-term;
  file `candidates_churn_level96w2.json`).
- Level 96, weight 4: **not searched** — 951,191 holomorphic
  eta-quotients enumerated, but the sparse-relation search at that
  scale is out of reach with current tools (would need
  newform-decomposition methods, not nullspace over the full set).
  Clean partial negative for the search method, not for the math.

All 421 verified to 200 q-expansion terms (Sturm bound for N=96 w=2
is 32; for N=64 w=4 is 16 — all far exceeded, so each is a theorem).

**Verification status.** All verified to 200 terms; spot-checked
independently (L64 w=2/w=4 samples confirmed).

**Novelty notes.**
- Screened: primitive, lcm(support)=96 for the level-96 batch
  (genuinely new at 96, not oldforms), not a q→q^m substitution of
  MF-001..015 / W-001..030.
- Caveat: the 385 level-96 relations are distinct term-sets, but
  independence among them was not fully analyzed — some may be linear
  combinations of others in the same span (many share terms). The
  3-term ones (201) are the most likely to be atomic.
- Literature status: same as before — sparse homogeneous vanishing
  relations are not tabulated in the surveyed literature; provisional.

## Direction 4 — New exact-tail family: CYCLIC-ROOT RADICALS (verified)

**Proposal.** A genuinely new exact-tail family, distinct from the
existing nested / scaled / cf / qcf / mixed / qrad masters:
root degrees **cycle with period 3** through (2, 3, 4).

**Master statement.** For integer c ≥ 2, let P(n) = n + c and let
m_n = 2, 3, 4 according as n ≡ 0, 1, 2 (mod 3). Define
A(n) = P(n)^{m_n} − P(n+1) (> 0 for c ≥ 2). Then

    c = ( A(0) + ( A(1) + ( A(2) + ⋯ )^{1/4} )^{1/3} )^{1/2}

i.e. the infinite radical with root degrees cycling 2, 3, 4, 2, 3, 4, …
evaluates exactly to c.

**Parameter ranges.** c ∈ ℤ, c ≥ 2 (c = 1 fails: A(0) = 1² − 2 < 0).
The construction works for any period and any root-degree cycle with
all degrees ≥ 2; (2,3,4) is the minimal new case (the existing `mixed`
family is the period-2 cycle (2,3) without 4th roots).

**Proof sketch.** Exact tails: P(n)^{m_n} = A(n) + P(n+1) by
definition of A(n). Truncation error contracts by a factor
≈ 1/(m_n · P(n+1)^{m_n−1}) ≤ 1/(2(n+c+1)) per level, so the
truncations converge to P(0) = c.

**Numerical verification** (mpmath, 50 digits, tail N=300):
- c=2: 2 = √(1 + ∛(23 + ∜(251 + √(19 + ∛(209 + ∜(2393 + ⋯)))))) — error 0.0
- c=3: 3 = √(5 + ∛(59 + ∜(619 + √(29 + ∛(335 + ∜(4087 + ⋯)))))) — error 0.0
- c=5: 5 = √(19 + ∛(209 + ∜(2393 + √(55 + ∛(719 + ∜(9989 + ⋯)))))) — error 0.0

Script: `/tmp/cyclic.py`.

**Novelty notes.** Not a parameter variation of any existing family:
the mixed family cycles (2,3); this cycles (2,3,4) — a different
iteration shape with a new root degree (4th roots) in the cycle.
The exact-tail construction is the same method, but the family
itself (statement + parameter range) is new. Suggested addition to
the masters page as a 5th master ("Cyclic-Root Radicals").
